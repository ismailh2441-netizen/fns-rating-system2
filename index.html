The page loaded, but the app did not. This is usually caused by one of these:

  • The browser is blocking cookies / site data for this site.
  • The browser is an old version that can't run this app.
  • A network filter, ad-blocker or antivirus blocked one of the files.

Try a hard reload first: Ctrl+F5 (or Cmd+Shift+R on Mac).

If it still fails, allow site data for this address, try the latest Chrome or Edge, or send a screenshot of the browser console (F12 → Console).
